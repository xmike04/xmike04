## Evidence

- **Retrieval engineering and evaluation:** Built [RAGOps](https://github.com/xmike04/RAG_OPS), a FastAPI/PostgreSQL/pgvector/Redis platform with asynchronous ingestion, RRF, metrics, and a React operations console. Its separate offline SciFact experiment used 5,183 documents and 300 held-out queries: RRF achieved 0.8059 Recall@10 and 0.6816 nDCG@10. The serving application uses PostgreSQL cover-density lexical ranking and sequential retrieval. A historical local-provider HTTP run recorded 24.56 ms p50 and 31.75 ms p95 over 9,234 requests to one repeated query; generation was excluded. The experimental cross-encoder reduced held-out quality and remains a negative result. [Sources, configurations, and limits](https://github.com/xmike04/xmike04.github.io/blob/046f3c12902ff91cf35e8013493188f010bd97af/docs/evidence/claims.md#ragops-retrieval).
- **AI product evaluation:** Worked as a Product Analyst Intern on Mr. Cooper Group's AI/ML team in 2025, supporting agentic-AI customer-service products through experimentation, user validation, feature evaluation, and cross-functional delivery.
- **Computer vision leadership:** As lead developer for a **UNT senior capstone (Fall 2024–May 2025)**, led a five-person student team building the NASA PACE **WAVE: From Space to Ocean** interactive exhibit. We met regularly with NASA PACE collaborators and coordinated with University of Maryland partners. The work used OpenCV, CUDA, Unity, C#, React, TypeScript, and ZED stereo cameras, and the installation premiered at the Kennedy Center in Washington, D.C., in March 2025.
- **LLM systems:** Built [SIMLYFE](https://github.com/xmike04/SIMLYFE), a life simulator separating deterministic game logic from authenticated, schema-validated event generation. [CI on October 26, 2026](https://github.com/xmike04/SIMLYFE/actions/runs/40374004252) passed 783 Vitest test cases across 37 files plus controlled desktop/mobile browser flows. The public frontend is hosted; a fresh live authentication/event/save journey remains pending. [Current deployment evidence](https://github.com/xmike04/SIMLYFE/blob/3d2b1bee5e65885e2d48e48e175a25862a52ff6b/docs/operations.md#october-26-2026-metadata-inspection).
